为什么叫 slides2video？

名字背后
的逻辑

slides

一张一张的幻灯片 — HTML、PPT、图片都算。
本项目以 HTML 为核心，用浏览器截图精准还原每一帧。

2 (to)

"转换" — 技术上是截图 + TTS + ffmpeg 三步流水线，
对用户来说就是一个命令。

video

带 AI 解说的 MP4，可以直接上传到任何平台。
无需剪辑软件，无需录音。

项目起源

程序员的
视频困境

我是一个程序员，在历史上深受做视频的困扰，但又不得不做——因为开发的大量项目确实需要用视频来教大家如何使用。
1
文档没人看 信息快餐时代，用户没时间认真读文档
2
视频费时费力 录屏、剪辑、配音……一个视频半天没了
3
项目多、视频需求多 每次新项目都要重复这个痛苦
信息快餐时代

优雅的视频
是最好的文档

用视频来呈现如何使用软件或写代码，是目前效率最高的方式之一。

幻灯片转视频

是目前数量最多的一种视频形式之一。
从 PPT 到 MP4，只差一个脚本的距离。

我坚定要找到一种能快速帮我生成视频的方案，这就有了今天的 slides2video 项目。

这个项目只是一个开始——更多幻灯片转视频的方式会陆续加入。

使用方法

你只需要
准备两件事

① 创建一个目录，放入 HTML 版 PPT

HTML 版 PPT 可以直接让 AI Agent 帮你生成。
MiniMax、Kimi、DeepSeek……随便哪个都能做，
告诉它"帮我做一个 HTML 幻灯片"，复制粘贴保存为 index.html 即可。

② 在同一目录下放 scripts.json

JSON 数组，每条字符串是一张幻灯片的解说词。
同样可以让 AI 根据幻灯片内容自动生成。

my-project/
  index.html   # HTML 幻灯片
  scripts.json # 解说词
原理

三步生成
视频

1
截图 — Playwright 无头 Chromium 逐页截取 index.html，得到 slide_01.png …
2
配音 — 豆包 TTS 按 scripts.json 调用豆包 V3 API，生成 PCM 音频
3
合成 — ffmpeg 图片 + 音频编码为 MP4，PCM 直接拼接保证零间隙
# 一条命令
node generate-video.mjs ppt/my-project
Step 1 — HTML 幻灯片

让 AI 帮你
做 PPT

不用自己写 HTML。把你的内容发给任意 AI：

MiniMax Kimi DeepSeek Claude ChatGPT

让 AI 生成后，保存为 index.html，放入你的项目目录。
确保每张幻灯片是 .slide div，并暴露 window.goTo(i)：

<!-- 每张幻灯片 -->
<div class="slide active">
  <h1>第一页标题</h1>
  <p>内容</p>
</div>
<div class="slide">...</div>

在 JS 中暴露 window.goTo(i) 供 Playwright 调用翻页。

window.goTo = function(i) {
  slides.forEach((s,j) =>
    s.classList.toggle('active', j===i));
};
Step 2

编写 scripts.json

在项目目录下创建 scripts.json，
每个字符串对应一张幻灯片的解说词。

// 简单数组
[
  "第一页的解说内容。",
  "第二页的解说内容。",
  "..."
]

也可指定声音：

{
  "voice": "zh_male_jieshuonansheng_mars_bigtts",
  "scripts": ["...", "..."]
}

查看所有声音：node generate-video.mjs --list-voices

Step 3

运行 & 输出

确保 .env 已配置豆包 API Key：

DOUBAO_APP_ID=your_app_id
DOUBAO_ACCESS_TOKEN=your_token

运行：

node generate-video.mjs ppt/my-project

# 断点续跑
node generate-video.mjs ppt/my-project \
  --skip-screenshots

# 查看所有声音
node generate-video.mjs --list-voices 男

输出：ppt/my-project/output.mp4
