为什么叫 slides2video？

名字背后
的逻辑

slides

一张一张的幻灯片 — HTML、PPT、图片都算。
本项目以 HTML 为核心，用浏览器截图精准还原每一帧。

2 (to)

"转换" — 技术上是截图 + TTS + ffmpeg 三步流水线，
对用户来说就是一个命令。

video

带 AI 解说的 MP4，可以直接上传到任何平台。
无需剪辑软件，无需录音。

项目起源

程序员的
视频困境

我是一个程序员，在历史上深受做视频的困扰，但又不得不做——因为开发的大量项目确实需要用视频来教大家如何使用。
1
文档没人看 信息快餐时代，用户没时间认真读文档
2
视频费时费力 录屏、剪辑、配音……一个视频半天没了
3
项目多、视频需求多 每次新项目都要重复这个痛苦
信息快餐时代

优雅的视频
是最好的文档

用视频来呈现如何使用软件或写代码，是目前效率最高的方式之一。

幻灯片转视频

是目前数量最多的一种视频形式之一。
从 PPT 到 MP4，只差一个脚本的距离。

我坚定要找到一种能快速帮我生成视频的方案，这就有了今天的 slides2video 项目。

这个项目只是一个开始——更多幻灯片转视频的方式会陆续加入。

使用方法

你只需要
一个目录
两个文件

my-project/
  index.html   # HTML 幻灯片
  scripts.json # 每页解说词

就这两个文件，其他全自动。

Step 1 — HTML 幻灯片

让 AI 帮你
做 PPT

不用自己写 HTML，发给任意 AI 让它生成：

MiniMax Kimi DeepSeek Claude ChatGPT

生成后保存为 index.html，放入项目目录即可。

Step 1 — 结构要求

HTML 结构

每张幻灯片是一个 .slide div，JS 暴露 window.goTo(i)：

<div class="slide active">第一页</div>
<div class="slide">第二页</div>
window.goTo = function(i) {
  slides.forEach((s,j) =>
    s.classList.toggle('active', j===i));
};
原理

三步生成
视频

1
截图 — Playwright 无头 Chromium 逐页截取幻灯片
2
配音 — 豆包 TTS 按 scripts.json 生成 AI 配音
3
合成 — ffmpeg 图片 + 音频合成 MP4，零间隙
Step 2 — 解说词

编写
scripts.json

每条字符串对应一张幻灯片：

[
  "第一页解说词。",
  "第二页解说词。"
]

指定声音（可选）：

{
  "voice": "zh_male_jieshuonansheng_mars_bigtts",
  "scripts": ["..."]
}
Step 3 — 运行

一条命令
生成视频

# 生成视频
node generate-video.mjs my-project

# 查看所有声音
node generate-video.mjs --list-voices

# 断点续跑
node generate-video.mjs my-project --skip-screenshots

输出：my-project/output.mp4
